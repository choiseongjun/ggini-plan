# 요즘 많이 비교한 음식

- 한국 홈에서 최근 한국 시간 7개 날짜의 비교 선택 상위 6개 상품을 표시한다. 3회 이상 집계된 상품만 노출한다.
- 한국 상품 비교 체크박스 추가와 앱 내 가격 비교 버튼 클릭만 집계한다. 페이지 조회, 선택 해제, 재렌더링은 집계하지 않는다.
- 운영 Vercel 환경에서만 기록한다. 한국 상품만 허용하며 같은 접속 주소의 같은 상품은 하루 한 번, 하루 최대 50종까지 기록한다. 공유 네트워크의 중복도 합쳐질 수 있으므로 사람 수나 구매 수로 표시하지 않는다.
- 접속 주소 원문이나 계정 ID는 저장하지 않는다. 서버 비밀을 사용한 날짜별 HMAC만 저장하며 최근 7일 범위 밖의 기록은 후속 기록 요청에서 정리한다. 비밀 변경 시 중복 방지 키도 바뀐다.
- 결과가 없으면 집계 중 안내, 조회 실패면 오류 안내를 표시한다. 가짜 순위나 상품으로 대체하지 않는다. 결과 캐시는 최대 5분이다.
- `db/comparison-interest.sql`을 배포 전에 적용한다. DB 검증은 트랜잭션 롤백으로 테스트 이벤트를 남기지 않는다.
