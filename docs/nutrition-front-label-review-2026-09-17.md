# 누락 영양정보 재검토

500개 상품 중 하나 이상의 수치가 누락된 79개를 재조회했다. 기존 포장 표시사항 사진을 다시 확인하고, 컬리 상품 데이터의 별도 `sizeImages`에 있는 포장 전면 이미지 39개를 추가 확인했다.

## DB에 반영한 값

| 상품 | 기준량 | 열량 |
| --- | --- | --- |
| 청정원 미니돈카츠 | 총 340g | 952kcal |
| 베키아에누보 트러플 감자 스프 | 총 180g | 236kcal |
| 사자표 거장 짜장소스 | 총 250g | 355kcal |

모두 해당 상품 포장 전면에 표시된 숫자다. 원문 판매 링크와 사진 링크는 `data/catalog-nutrition-front-labels-2026-09-17.json`에 보존하고 DB에도 저장했다. 단백질·탄수화물·지방·나트륨은 공개 자료에서 확인하지 못했으므로 null로 유지했다.

적용 결과: 전체 500개, 5개 영양값 모두 등록 421개, 일부 등록 20개, 전체 미확인 59개. 79개 전부를 채운 것은 아니다. 생고기·채소의 일반 평균값, 일부 구성품 영양표, 서로 다른 버전의 유사 상품 수치, `1g 미만` 표기를 임의 숫자로 대체하지 않았다.

## 재실행

`node --env-file=.env.local scripts/apply-nutrition-backfill.mjs --manifest data/catalog-nutrition-front-labels-2026-09-17.json`

기본은 dry run이며 `--apply`를 추가하면 반영한다. 조사 시점의 상품정보·기존 영양값·출처와 비교해 충돌을 보존한다. 적용 전후 기록은 로컬 `data/nutrition-review/applied-1789610554497.json`에 저장했다. 업데이트 후 DB를 재조회해 세 값과 최종 집계를 확인했다.
