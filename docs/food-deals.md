# 식품 핫딜 1차 운영

- `/deals`: 종류·출처 필터, 조건 적용 가격·판매 구성·배송비·원문 링크. 기본 목록은 공개 상태이면서 종료되지 않고 24시간 이내 확인된 항목이다.
- `/admin/deals`: 원문 기반 수집·검토 대기·공개·종료 관리. 공개 시 확인 체크가 필요하다. 원문 URL 중복을 막으며 한국 상품에만 연결한다.
- 커뮤니티 글을 자동으로 복제하지 않는다. 제휴/API/피드의 이용 가능 여부가 확인되기 전까지 운영자가 사실을 확인해서 요약 등록한다. 현재 자동 크롤링·예약 수집은 연결하지 않았다.
- 원문 본문·사진을 복제하지 않고 출처로 연결한다. 가격·쿠폰·배송·구성은 따로 확인한다. 링크만 등록해 영양이나 할인율을 추정하지 않는다.
- 기존 상품 연결은 상세 정보 참조용이다. 행사 가격은 상품 기본 가격이나 식단 계산에 자동 반영하지 않는다.
- 검토 대기 상태는 공개 조회에서 제외된다. 시간 경과 상태는 조회 시 계산하므로 별도 스케줄러 없이 기본 목록에서 제외된다.
- 배포 전 `db/food-deals.sql` 적용. 가격·영양 데이터를 임의로 채우지 않으며 비어 있거나 조회 실패 시 해당 안내를 표시한다.
