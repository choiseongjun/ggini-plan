# 식품 핫딜 자동 수집

- /deals: 할인율 내림차순. 정상가 미확인은 뒤로. 식재료·냉동식품·밀키트·간편식 필터.
- /admin/deals: 지금 수집(약 45초/최대 60개), 일일 자동 수집 켜기/끄기, 최근 기록, 직접 수정.
- 현재 출처는 컬리 공개 상품 페이지. 기존 한국 상품과 공개 사이트맵 URL을 순환 확인한다. 제한된 API는 사용하지 않는다.
- 매 실행 robots 확인. 고정 HTTPS 호스트/경로, 리다이렉트 거절, 350ms 간격, 10초/5MB 제한. HTTP 403/429 즉시 중단.
- 동일 단일 구성의 basePrice 대비 discountedPrice로 할인율 계산(소수 둘째 자리 내림). 쿠폰 제외. 모호한 옵션/회원 제한/최소 수량/비식품 제외.
- 정상 할인은 자동 공개. 품절·할인 종료·모호한 구성은 종료. 파싱/통신 오류는 확인 시각을 유지. 자동 상품 36시간, 수동 24시간 경과하면 재확인 필요.
- 기존 영양/가격 DB를 덮어쓰지 않는다. 관리자가 핫딜을 직접 수정하면 자동 갱신을 해제하고 할인율을 비운다.
- db/food-deal-collection.sql 적용 필요. DB 잠금, 10분 하트비트 만료, 2분 실행 간격.

## 일일 작업

.github/workflows/food-deals.yml: 매일 UTC 00:00(한국 오전 9시 이후, GitHub 지연 가능). Actions secret FOOD_DEALS_DATABASE_URL 필요.
최대 2,500개/38분; 남은 후보는 다음 실행에 이어서 수집. 10%는 사이트맵 신규 상품 탐색. 설정 끄기는 이후 일일 실행을 건너뛰며 현재 진행 중인 작업은 중단하지 않는다.
수동 운영 실행: node --env-file=.env.local --import tsx scripts/collect-food-deals.ts 또는 workflow_dispatch.
자동 확인은 사람 검수나 전체 쇼핑몰 최저가 보장이 아니다.
