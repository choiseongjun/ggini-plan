# 구매 상태와 보유 수량

- 간편식 추천과 식단에서 담은 재료에 `살 것 / 주문한 것 / 보유 재료`를 표시한다.
- 여러 항목 선택, 일부 수량 주문·수령·사용, 주문 표시 취소, 오프라인 구매, 기존 보유 등록을 지원한다.
- 판매처 링크를 여는 것만으로 주문 처리하지 않는다. 사용자가 주문했다고 확인해야 이동한다.
- 판매처 도메인별 상품 링크와 목록 복사를 제공한다. 외부 장바구니 자동 담기, 결제, 배송 추적 API는 연결하지 않았다.
- 계정별 상태는 `shopping_progress`에 저장하며 버전 조건으로 동시 수정 덮어쓰기를 막는다. 충돌 또는 저장 실패 시 새로 불러온 뒤 수정해야 한다.
- 비회원은 브라우저 localStorage에 별도 저장하며 로그인 계정에 자동 합치지 않는다. 추천 초안도 계정별 localStorage 키를 사용한다.
- 간편식은 판매 묶음, 직접 요리 재료는 레시피 기준 g/mL로 관리한다. 조리 전후 단위를 임의 환산하지 않으므로 두 목록의 재고는 별도로 관리한다.
- 재료의 판매 단위가 확인되면 구매 처리 기본 수량을 판매 묶음에 맞춰 올림한다. 수령 수량이 이후 구매 필요량에서 차감된다. 이미 주문한 수량도 추가 구매량에서 제외한다.
- 간편식 추천 예산은 보유·주문 수량을 제외한 추가 구매 비용 기준이다. 실제 섭취는 자동 기록하지 않으며 보유 목록에서 직접 차감한다.
- 과거 `이미 있어요` 체크는 유지한다. 해당 체크를 해제한 뒤 수량 관리로 전환할 수 있다.

## 데이터베이스 적용

새 환경에는 `db/schema.sql`을 적용한다. 기존 환경에는 `db/shopping-progress.sql`만 적용할 수 있다. 이번 작업에서는 현재 DATABASE_URL 환경에 해당 테이블을 적용했다.
