# 추천 후보와 재추천 개선 (2026-09-18)

- 기존 검수 상품 39개에 수집 근거의 상품명·구성·URL·단위·수량이 일치하는 후보를 연결했다. 판매 상품 후보는 167개이며, 실제 조건에 따라 줄어든다.
- 총중량·명시된 인분/개입을 해석해 판매 구성을 나눈다. 단일 구성은 일반적인 포장량 범위만 허용한다. 서로 다른 개입 수, 옵션, 대용량, 해석하지 못한 묶음은 제외한다. 이는 상품의 권장 섭취량이나 검증된 영양 1회분이라는 뜻이 아니다.
- 김밥 햄·단무지·샌드위치 피클·크래커·소스·찌개두부 등은 한 끼 후보에서 제외한다. 밥 포함 여부가 불명확한 비빔밥 재료 세트도 제외한다.
- 국·찌개·제육볶음 1회분과 기존 현미밥 210g 상품을 조합한 70개 후보를 추가했다. 조합은 실제 상품별 구매 묶음을 합산하고, 먹은 양만 재고에서 차감하며 취소 시 복원한다.
- 조합은 간편식 모드에 포함하며 직접 조리 레시피와 구분해 표시한다. 조리 시간은 임의로 정하지 않고 각 포장의 안내를 따르도록 표시한다.
- 영양값이 없으면 미확인으로 유지한다. 조합의 일부라도 영양을 확인할 수 없으면 전체 합계도 미확인이다. 제외 재료가 지정되면 기존의 미확인 알레르기 필터를 그대로 적용한다.
- 직전 추천을 컴포넌트에서 기억해 설정으로 돌아갔다 다시 추천할 때 같은 상품과 음식 종류의 우선순위를 낮춘다. 영구적인 식사 이력 저장 기능은 아니다. 후보가 적거나 예산이 제한되면 반복할 수 있다.
- 큰 후보군에서는 가격·보유분과 음식 종류를 고려해 탐색 후보를 제한한다. 예산은 실제 판매 묶음 합계의 상한이며, 탐색 결과가 수학적인 최적해임을 보장하지 않는다.
- 추천과 예산 안내 계산은 Web Worker에서 실행해 화면을 막지 않는다.

검증: 포장 해석, 잘못된 재료 후보 차단, 판매 단위 변경, 조합 구매·소비·복원, 영양 미확인, 예산·제외 재료·재추천 회귀 테스트. 로컬 브라우저에서 추천/재추천과 결과 포커스 확인. 한국 2,000개 카탈로그 기준 추천 후보는 판매 167 + 조합 70 + 기존 요리 조합 99 = 336개.
