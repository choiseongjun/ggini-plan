# 함께 기능

하단 함께 탭에서 장바구니 공유, 도움됐어요 반응, 대체·소분 팁, 주간 챌린지를 제공합니다. 읽기는 비로그인 가능하며 쓰기는 세션 로그인이 필요합니다. 이름·이메일·신체정보는 공개 응답에서 제외하고 사용자가 입력한 별명만 표시합니다.

## 저장 구조

`community_posts`, `community_likes`, `community_tips`, `community_challenges`, `challenge_members`, `challenge_checks`, `community_baskets`를 `npm run db:migrate`로 만듭니다. 샘플 사용자 게시글은 넣지 않습니다. 챌린지 정의 세 개만 등록합니다.

## API

- GET /api/community: 최근 게시글 30개(각 최근 팁 30개), 이번 주 챌린지와 내 참여 상태, 내 따라 담은 장바구니.
- POST /api/community: action으로 share, like, tip, delete-post, delete-tip, adopt, join, check를 구분합니다.
- 게시글·팁 삭제는 작성자만 가능합니다. 게시글 삭제 시 팁과 반응을 함께 삭제하지만 이미 따라 담은 개인 장바구니는 유지합니다.
- like의 liked, check의 checked는 원하는 상태를 지정하여 중복 요청에 같은 결과를 보장합니다.
- 한국 시간 월요일을 주 시작으로 사용하며 챌린지는 하루 한 번 체크할 수 있습니다. 오늘 체크는 취소할 수 있습니다.

## 내 조건으로 담기

저장된 신체 정보와 식단 취향이 필요합니다. 원문 상품을 현재 카탈로그 가격으로 다시 확인하고 제외 재료·식물성 취향을 적용한 후 가격 오름차순으로 예산 내 상품을 선택합니다. 상품은 한 묶음씩 담습니다. 기존 따라 담은 장바구니를 교체합니다.

개인 장바구니와 개인 칼로리 기준 식단 이력을 트랜잭션으로 저장합니다. 현재 두 계산은 별개이며 장바구니가 추천 식단의 모든 재료나 하루 영양량을 충족한다는 보장은 하지 않습니다. UI에도 이 제한을 표시합니다. 따라 담은 장바구니는 장바구니 탭 상단에서, 식단은 마이에서 확인합니다.

## 검증

npm run test:community

비로그인 쓰기 차단, 공개 정보, 작성자 권한, 중복 반응, 대체 팁, 개인별 담기, 예산·제외 재료 반영, 챌린지 중복 체크 방지와 취소를 임시 계정으로 검증하고 테스트 데이터를 정리합니다.
