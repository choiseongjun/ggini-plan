# 내 컴퓨터에서 한국 상품 수집하기

프로젝트 폴더에서 터미널을 열고 실행합니다. Node.js와 프로젝트 의존성, `.env.local`의 `DATABASE_URL`이 필요합니다. DB는 현재 운영 Supabase입니다.

```powershell
npm run catalog:expand -- --target=2000
```

Windows에서는 프로젝트 폴더의 `collect-korean-products.cmd`를 더블클릭해도 같은 작업을 실행합니다. 현재 DB 개수와 저장된 수집 진행량은 `npm run catalog:status`로 확인합니다.

한국 상품의 **전체 개수**를 2,000개까지 늘립니다. 대만 상품은 목표 개수에 포함하지 않습니다. 공개된 컬리 검색·상세 페이지의 상품명, 실제 표시 가격, 이미지, 판매 구성, 구매 링크, 알레르기·영양 표시 출처를 수집합니다. 회원 로그인이나 유료 AI API는 필요하지 않습니다.

목표 수량을 수집한 뒤 신규 상품만 운영 DB에 등록합니다. 기존 상품·사용자 기록은 덮어쓰지 않습니다. 상품 ID·구매 URL·정규화한 이름으로 중복을 거릅니다. 판매 중단, 복수 옵션 가격, 비식품·간식 잡음은 제외하며 영양 수치나 인분을 추정해 입력하지 않습니다. **등록 상품 수와 영양·인분 검증을 마친 식단 추천 가능 상품 수는 다릅니다.**

터미널을 열어 두고 컴퓨터가 절전 모드에 들어가지 않도록 해 주세요. 중간에 껐다면 같은 명령을 다시 실행하면 됩니다. 진행 결과는 `data/catalog-kr-2000.json`에 페이지마다 저장합니다. 목표 개수를 바꾸면 별도의 파일을 사용합니다. 같은 목표의 수집 작업을 여러 창에서 동시에 실행하지 마세요.

서버가 403 또는 429를 반환하면 차단을 우회하거나 반복하지 않고 저장 후 중단합니다. 판매처 구조 변경·수집 가능한 상품 부족으로 목표에 도달하지 못할 수 있습니다. 이 경우 종료 코드 2를 반환하며 자동 등록하지 않습니다.

수집 결과를 먼저 살펴보려면 다음처럼 분리해서 실행할 수 있습니다.

```powershell
npm run catalog:collect -- --target=2000
# JSON 결과를 검토한 뒤, 수집된 신규 상품만 등록
npm run catalog:apply -- --target=2000
```

실시간 가격 연동이나 예약 실행은 아닙니다. 이미 등록된 상품의 가격을 갱신하는 작업도 별도입니다. 가격은 수집 시점 기준이며 배송비·쿠폰 적용 전입니다. 수집량을 늘려도 영양 라벨 검수와 적절한 1회분 연결은 별도로 필요합니다.
