# K-FIND 영양 데이터 보강

`data/tempdata`의 공식 XLSX를 기존 식약처 데이터에 추가하는 가져오기 경로다.
레시피나 조리법을 생성하지 않으며 원본 파일과 기존 원재료는 유지한다.

## 실행

1. `openpyxl`이 있는 Python으로 `scripts/extract-kfind.py`를 실행한다.
   기본 입력은 `data/tempdata`, 출력은 Git에서 제외되는 `.cache/kfind`다.
   다른 경로는 순서대로 인자를 전달한다. 추출은 읽기 전용이며 중간 결과를 재사용한다.
2. `npm run foodsafety:validate-kfind`로 전체 행의 코드, 기준량, 주요 영양값,
   파일 체크섬 및 행 수를 검사한다. DB에는 쓰지 않는다.
3. `npm run foodsafety:import-kfind`로 `.env.local`의 `DATABASE_URL`에 적용한다.
   이 명령도 쓰기 전에 전체 검증을 수행한다. 다른 기존 마이그레이션은 실행하지 않는다.

## 보존 및 병합 규칙

- 원본 XLSX SHA-256, 시트명, 모든 열 이름을 `kfind_import_files`에 보존한다.
- 빈 셀을 제외한 원본 값을 `kfind_nutrition_snapshots.raw_record`에 JSONB로 저장한다.
  원래 문자열과 0을 보존하며 원본 기준일도 기록한다. 상세 영양성분은 이 테이블에 있다.
- `kfind_nutrition_latest`는 완료된 가져오기 중 식품코드별 최신 원본만 보여준다.
  기존 기본 영양값과 원본 값은 출처·기준량을 확인해서 사용해야 하며 무조건 합치지 않는다.
- 기존 음식 코드의 주요 영양값은 덮어쓰지 않는다. 기준량이 같은 경우 NULL만 보강한다.
  이름이나 기존 1회분량도 유지한다. 상충하는 기존 수치는 보고서에 집계한다.
- 새 음식·가공식품을 `foodsafety_processed_nutrition`과 `food_reference`에 추가한다.
  가공식품 전체 포장 무게를 임의로 1회 섭취량으로 취급하지 않는다.
  1회 섭취참고량이 없거나 단위가 다르면 기준량으로 조회된다.
- 건강기능식품은 원본 테이블에만 `SUPPLEMENT`로 저장한다. 일반 식사/추천에 넣지 않는다.
- 기존 RAW 데이터나 새 파일에 없는 식품을 삭제하지 않는다.
- 일반 식품 테이블 변경은 한 트랜잭션으로 적용한다. 실패하면 이 변경은 롤백된다.
  원본 보관은 배치 단위이며 중단된 파일은 완료 뷰에서 보이지 않는다. 재실행 가능하다.
- 변경 직전 기존 행과 새로 추가할 식품코드 목록을 `.cache/kfind/before-*.jsonl.gz`에 저장한다.
  `import-report.json`에 백업 경로, 추가·보강 건수와 처리 전후 통계를 남긴다.
  복구 시 해당 실행의 백업만 사용하고, 이후 변경된 데이터와 먼저 대조한다.

상세 영양성분은 보존하지만 이번 작업이 모든 UI에 미량영양소를 표시하는 것은 아니다.
이전 벌크 API 스크립트는 덮어쓰기 방식이므로 보강된 기본값을 다시 교체할 수 있다.
공식 XLSX 보강에는 이 새 경로를 사용한다.

## 테스트

`node --env-file=.env.local --test tests/kfind-import.test.mjs`

DB 병합 테스트는 임시 테이블에서만 실행하고 롤백한다. 환경변수가 없으면 순수 변환
테스트만 실행한다. 기존 값과 0 보존, 단위 불일치, 기존 전용 행 유지, 재실행을 검사한다.
# 상세 영양성분 표시

`GET /api/food-reference/nutrients?code=식품코드`는 완료된 최신 원본에서 제공된 모든 영양성분을 반환한다. 음식(D)·가공식품(P)만 지원하며 건강기능식품과 이름만 입력한 기록은 대상이 아니다.

음식 검색 선택 화면, 칼로리 상세 페이지, 참고 음식 비교, 식사 기록, 정부DB 기반 추천 레시피에서 `DetailedNutrition`으로 펼쳐 볼 수 있다. 열 때만 조회하며 원본 기준량·출처·기준일을 함께 표시한다. 선택한 중량/부피가 원본과 같은 단위 계열일 때만 환산한다. 원본의 0은 유지하고 미제공 값은 표시하지 않는다.

기존 식사 기록은 최신 원본 기준량의 참고값이며 과거 섭취량을 재계산하지 않는다. 추천 레시피에서는 목표 음식의 원본 참고값으로 표시하며 밥·반찬·재료 합계로 취급하지 않는다. 하루 상세 영양소 합계는 이번 변경에 포함하지 않는다.
