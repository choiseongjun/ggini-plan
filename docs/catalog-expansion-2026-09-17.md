# 상품 카탈로그 500개 확장

2026-09-17: 기존 114개 유지, 신규 386개 추가. DB 및 로컬 `/api/catalog`에서 총 500개 확인.

## 범위

- 컬리 공개 검색 결과와 개별 상품 상세의 판매 정보를 수집했다. 실시간 동기화는 아니다.
- 단일 판매 구성, 구매 가능 여부, 표시 가격, 중량/구성, 상품 이미지 응답을 확인했다.
- 상품 ID·URL·상품명 중복을 배제했다. 기존 행은 수정하지 않았다.
- 신규 상품은 기본 주간 장바구니에 자동 추가하지 않는다.
- 파스타 관련 45개, 피자 25개, 스테이크 관련 20개, 라자냐 7개, 뇨끼 8개 등을 포함한다. 관련 상품 수에는 면·소스·생고기 등 식재료도 포함된다.
- 양식 관련 총 170개, 멕시칸 15개, 아시아식 48개, 일식 37개, 중식 35개, 한식 81개를 추가했다. 요리권 분류는 수집용 메타데이터이며 관리자 UI의 기존 카테고리를 변경하지 않았다.
- 검색 결과에 섞인 식기·반려동물식·과자는 검토 후 제외했다.

## 검수 제한

신규 386개의 영양 수치는 아직 입력하지 않았다. 알레르기 역시 `unknown`으로 등록했으며, 빈 성분 배열은 알레르기 없음이라는 의미가 아니다. 상품 원문 및 제공된 표시사항 이미지 링크를 저장해 후속 검수에 사용할 수 있다. 원문 이미지가 없는 상품도 있다. 이전 114개의 검수 정보는 그대로 유지했다.

이번 확장은 상품 테이블 대상이다. 기존 식단 자동 추천의 검증된 상품 목록·인분 기준은 변경하지 않았다. 500개 모두가 자동 식단 추천 대상이 된 것은 아니다.

## 실행 및 검증

- `node --env-file=.env.local scripts/expand-diverse-catalog.mjs`: 수집만 수행
- `--resume`: 저장된 수집 결과에서 재개
- `--apply`: 현재 총 500개를 상한으로 신규 행만 추가
- 1차 적용: 386개 삽입. 재실행: 0개 삽입, 총 500개 유지.
- 기존 114개 전체 행을 적용 전 스냅샷과 비교하여 변경 없음 확인.
- `/api/catalog`: HTTP 200, 500개 반환.
- 관련 테스트 7개 통과, 추가 스크립트/테스트 ESLint 통과.

수집 결과: `data/catalog-expansion-2026-09-17.json`. 복구 검증용 기존 데이터 스냅샷은 Git 제외 경로 `data/nutrition-review/expansion-before.json`에 보관한다. 커밋·푸시·별도 배포는 하지 않았다.
