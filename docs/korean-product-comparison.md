# 한국 상품 비교와 검색 확장

- /products: 한국 판매 상품 목록, 검색, 판매가·영양값 정렬, 최대 4개 비교.
- /foods/[kind]: 상품이 존재하는 음식 종류만 공개하며 종류별 구매 안내를 제공합니다.
- /products/[id]: 판매 옵션·가격 확인일·원문 영양표·원재료 확인과 관련 상품.
- 기존 /compare/[item] 판매처 비교 기능은 유지합니다.
- data/korean-search-topics.json: 100개 초기 검색어와 목적 페이지 매핑. 검색량 검증·노출 보장은 아니며 메타 키워드를 삽입하지 않습니다.

## 비교 원칙

영양정보는 원문 출처가 있고 g 또는 mL 기준이 하나로 확인될 때에만 100 단위로 환산합니다. 일반 식품 참고값·가식부·조리 전후가 명시된 값은 환산 비교에서 제외합니다. 100g과 100mL는 섞지 않습니다. 미확인은 0으로 채우지 않습니다. 판매가·단위 가격은 등록 옵션 기준이며 시작가를 표시하고 배송비는 별도임을 알립니다. 한 개를 한 끼로 가정하지 않습니다.

## 검색 처리

서버 렌더링 본문, 고유 제목·설명·대표 주소, 실제 상품 BreadcrumbList와 Product 정보, 공개 페이지 사이트맵. 검색·정렬 결과는 noindex, 기본 페이지 번호는 고유 대표 주소를 가집니다. 빈 종류와 잘못된 페이지 번호는 Next.js notFound 화면 및 noindex로 처리합니다. 스트리밍이 시작된 요청에서는 HTTP 200과 함께 notFound 화면이 반환될 수 있습니다. 개인 조건으로 자동 생성한 페이지를 무한히 공개하지 않습니다.
