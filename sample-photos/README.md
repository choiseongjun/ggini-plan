# 사진 인식 테스트 샘플

실제 촬영·구매 기록이 아닌, 내장 ImageGen으로 만든 테스트 이미지입니다.

로그인 후 로컬 홈 → 사진으로 재료 등록 → 사진 파일 선택 또는 드래그 → 사진에서 재료 찾기 → 결과와 보유 여부 확인 → 재료 등록 → 메뉴 추천 순서로 사용하세요. 사진 종류는 자동 분류합니다.

| 파일 | 선택할 종류 | 확인할 재료 |
| --- | --- | --- |
| 01-ingredients.png | 재료 실물 | 달걀, 양파, 당근, 애호박, 파, 두부, 김치 |
| 02-cart.png | 장바구니 | 달걀, 두부, 양파, 닭가슴살, 애호박 (키친타월 제외) |
| 03-receipt.png | 영수증 | 양파, 달걀, 두부, 김치, 파, 감자 (주방세제 제외) |

결과는 AI 인식에 따라 달라질 수 있습니다. 위 목록과 비교하고 이름을 수정하세요. 사진 분석은 보유 여부·수량을 확정하지 않습니다.

## 생성 프롬프트 요약

- 재료 실물: 한국 가정 주방에서 달걀·양파·당근·애호박·대파·두부·김치를 분리해서 찍은 사실적인 스마트폰 사진.
- 장바구니: 계란·두부·양파·닭가슴살·애호박과 키친타월이 들어 있는 한글 테스트 장바구니 화면. 개인정보 없이 샘플 표시.
- 영수증: 양파·계란·두부·김치·대파·감자와 주방세제가 적힌 한글 테스트 영수증을 나무 탁자 위에서 촬영한 이미지. 개인정보 없이 샘플 표시.
